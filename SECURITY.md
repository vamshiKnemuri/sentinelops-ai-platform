# Security Policy

Do not open a public issue containing credentials, account identifiers, production logs, or exploitable infrastructure details. Remove exposed access, rotate affected credentials, and use a private security report.

The project threat model and AI-specific controls are documented in [docs/SECURITY.md](docs/SECURITY.md).

The demonstration uses simulated remediation. Enabling a real mutation executor requires a separate identity, additional authorization, red-team testing, and explicit operator approval; it is outside the default project configuration.
